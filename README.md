# Duplicate Finder & Cleaner (Go CLI)

Высокопроизводительная консольная утилита на Go для параллельного поиска и удаления дубликатов файлов. 

Программа работает в два этапа: сначала фильтрует файлы по одинаковому размеру, а затем запускает процесс параллельного вычисления хешей на горутинах только для потенциальных кандидатов.

## Стек

* **Язык:** Go (Golang) 1.22+
* **Конкурентность:** `goroutines`, `channels`, `sync.WaitGroup`
* **Криптография:** `crypto/sha256`
* **Работа с ФС:** `path/filepath`, `os`

## Функционал

* **Быстрый двухэтапный поиск:** фильтрация уникальных размеров без лишней нагрузки на диск + параллельное хеширование дубликатов по размеру.
* **Пул воркеров (Worker Pool):** настраиваемое количество параллельных потоков обработки с эффективной утилизацией сетевого канала и CPU.
* **Интерактивное безопасное удаление:** автоматическое выделение первого файла в группе как оригинала и удаление только его копий.
* **Защита от Data Race:** потокобезопасная сборка результатов через изолированные каналы связи.

## Команды и Флаги

* `-path` — путь к сканируемой директории или сетевому диску (по умолчанию `.`). Принимает путь без кавычек.
* `-exclude` — исключения, файлы/папки, которые не нужно обрабатывать. Принимает пути без кавычек через запятую.
* `-delete` — флаг удаления. Принимает true/false или 1/0.

*Пример запуска:*

```
dups_cleaner.exe -path Z:\Backups -exclude Z:\Backups\main, Z:\Backups\test -delete true
```

## Установка и Сборка

1. Клонируйте репозиторий:
```
git clone https://github.com/your-username/dups-cleaner.git
cd dups-cleaner
```


2. Скомпилируйте проект в бинарный файл:
```
go build 
```


3. Запустите полученную утилиту:
```
./dups_cleaner.exe -path "C:\Users\User\Downloads"

```
